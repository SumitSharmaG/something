What it is

Snake is a grid-based arcade game: move continuously, collect items, grow longer and avoid collisions. A browser version needs a predictable game loop, input mapping, score state and a pause or restart path.

When it may help

A short casual game, a programming exercise in animation and state, or a demonstration of keyboard and touch interaction.

What you need

A modern browser. A completed version should provide arrow/WASD controls, touch controls for smaller screens, pause, restart and reduced-motion consideration.

How to approach it

  1. 01

    Start a new round when the game is implemented.

  2. 02

    Use directional controls to steer one grid cell at a time.

  3. 03

    Collect items while avoiding walls and the snake body.

  4. 04

    Pause or restart using visible, keyboard-accessible controls.

Limitations to keep in mind

The starter workspace does not contain a playable game. Collision rules, speed progression, saved scores and touch interaction remain implementation work.

Common questions

Can I play Snake here?

Not yet. The page describes the planned game and intentionally offers no pretend controls.

What controls should the finished game support?

At minimum, arrow keys and accessible touch controls, plus visible pause and restart actions.
